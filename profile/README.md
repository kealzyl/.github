# What if AI did not cost millions to train?
**A experiment focusing on methods to train AI for cheap**

</div>

<br>
The Kealzyl organization is a group of people that is trying to figure out methods of training AI's for hundreds instead of millions.

## Models :
1. [Kealzyl Pico](https://github.com/kealzyl/pico) : A very small LLM trained on only **one** wikipedia article.

   1.2. [Kealzyl Oxidum](https://github.com/kealzyl/oxidum) : Rewrite of Pico in rust.
  
3. [Kealzyl Caleum](https://github.com/kealzyl/caleum) : A tiny prediction model for the weather.
